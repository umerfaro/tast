# Design System Tokens & Guidelines

This document outlines the **visual design standards** for the *Ajaia Internal Suite*.

## Typography & Color Palette
- **Primary:** Deep Indigo (`#4f46e5`)
- **Canvas:** Pure White with soft elevation
- **Typography:** Inter sans-serif

## Core Principles
1. Clean visual hierarchy with zero distractions
2. Instant autosaving with explicit status indicators
3. Deterministic permission enforcement
