## 3. What Was Changed, Corrected, or Rejected After AI Output

Several initial AI outputs were actively caught, revised, or rejected during implementation:

1. **Vitest Module System Incompatibility**:
   - *AI Output*: Initial test file used CommonJS `const { describe, it } = require('vitest')`.
   - *Issue*: Modern Vitest 3+ enforces ESM imports and throws `Vitest cannot be imported in a CommonJS module using require()`.
   - *Correction*: Migrated test suite to `.mjs` with native ESM syntax (`import { describe, it, expect } from 'vitest'`), enabling zero-compilation test runs.
2. **Path-to-RegExp Express Wildcard Error**:
   - *AI Output*: Initial SPA catch-all used `app.get('*', ...)`.
   - *Issue*: Modern Express / `path-to-regexp` v8 threw `TypeError: Missing parameter name at index 1: *; visit https://git.new/pathToRegexpError for info`.
   - *Correction*: Replaced route wildcard with an idiomatic Express middleware fallback (`app.use((req, res, next) => { if (req.method === 'GET' && !req.path.startsWith('/api')) ... })`), eliminating route regex compilation errors completely.
3. **Supertest Assertion Property Bug**:
   - *AI Output*: Attempted to read `bobList.shared.some(...)` directly from Supertest response object.
   - *Correction*: Corrected to `bobList.body.shared.some(...)` to accurately inspect the JSON response body.
4. **TipTap Read-Only Mode & Toolbar Lockdown**:
   - *AI Output*: Initial editor component rendered formatting buttons without disabling them when viewing as a "Viewer".
   - *Correction*: Bound `disabled={!canEdit}` across all toolbar controls, added a dedicated view-only warning banner, and set `editor.setEditable(canEdit)` on persona changes.
5. **Design System & Elevation**:
   - *AI Output*: Generic default styling with basic buttons and unstyled contenteditable box.
   - *Correction*: Replaced with hand-tuned CSS design tokens, Google Fonts typography (Inter & JetBrains Mono), realistic paper canvas elevation (`--shadow-canvas`), Google Docs-like toolbar grouping, and responsive layout.
